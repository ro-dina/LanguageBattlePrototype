**Unityゲーム基盤整備の実装記録（2026年10月29日）**

対象はLanguageBattlePrototype、Unity 6000.4.8f1。Phase 1～4を実装しました。元プロジェクトはEditorで開かれていたため、作業用コピーで実装・検証し、確認済みのソースとテストのみ元プロジェクトへ反映しました。開始時のGit差分はありませんでした。

**変更後は、選択中のキャラID、キャラ別の確定装備、画面内の編集下書きを分けて管理します。**

従来はGameManagerの共通装備ID・共通配列と、GameDatabaseから取得したCharacterDataの変更が混在していました。現在はCharacterLoadoutStoreがキャラクターIDをキーに確定した変更だけを保持し、GetLoadoutは独立したコピーを返します。未変更のキャラはJSONマスターの初期装備・初期技を使います。保存するのは変更済みキャラの上書き状態です。

形容詞・冠詞と、順序付きの装備技・技ごとの副詞を同じCharacterLoadoutに含めます。既存UIには技自体を入れ替える選択画面がないため、新しいUIは追加せず、既存の副詞装備操作を維持しています。装備技の配列は保存・復元・詳細表示・戦闘へ接続してあり、Commit APIで変更できます。最大4枠は既存UIと同じです。

詳細画面の変更は下書きに留まり、Save／Confirm／Battleで確定します。Discardは下書きを捨て、Cancelは確認パネルだけを閉じます。キャラクター選択・図鑑のどちらから詳細を開いても同じ確定状態を使います。選択画面の能力表示も確定した形容詞補正を反映します。戦闘用CharacterDataはマスターから作るコピーで、プレイヤーの装備変更はJSONマスターを変更しません。

GameManagerの旧装備アクセサーは選択キャラのストアに委譲します。Sceneに保存されたSerializeField名、Buttonイベント、Scriptの既存meta/GUIDを維持しました。

**セーブはバージョン付きJSONで、状態が確定した時に共通サービスが保存します。**

通常の保存先はApplication.persistentDataPath配下のLanguageBattle/save.jsonです。このMacの設定では以下です。

`/Users/isao/Library/Application Support/DefaultCompany/My project/LanguageBattle/save.json`

形式はversion=1、inventory、ownedCharacters、characterEquipment、stageProgressです。所持品ID・個数、所有キャラID、変更済みキャラの形容詞・冠詞・装備技・副詞、解放済み／クリア済みステージIDを保存します。

PlayerSaveServiceはSceneロード前にGameDatabaseとともに起動します。DontDestroyOnLoadで維持し、Sceneに既存のGameDatabaseがある場合は従来の重複破棄処理を使います。新しいScene配置やScriptableObjectは追加していません。

InventoryManager、OwnedCharacters、CharacterLoadoutStore、StageProgressの確定変更をPlayerStateChangesへ通知し、PlayerSaveServiceに保存を集約しています。10連ガチャと合成はバッチ通知にまとめ、中間の素材消費状態を保存しません。編集下書きでは通知しません。既存のCaptureState／RestoreStateを利用しています。

保存時は内容とJSON往復を検証し、同一ディレクトリの一時ファイルへ書き込み、Flush後に置換します。既存ファイルが正常なら直前の内容を.bakへ保持します。書込失敗はログに記録し、ゲームへ例外を伝播させません。残った一時ファイルの削除も今回作成したものだけが対象です。

破損したsave.jsonは上書き・削除しません。有効な復旧ファイル、次にバックアップを試し、いずれも使えなければ新規状態へ復旧します。以後は同じフォルダのsave.recovery-日時-ID.jsonへ保存し、次回もその復旧データを読めます。破損したバックアップ・復旧ファイルも保持します。未対応バージョンは元ファイルを保持し、そのセッションの保存を停止して警告します。現在は旧セーブ形式が存在しないため、他バージョンからの移行処理はありません。

不明なアイテム・キャラ・技・装備ID、0以下の所持数、重複した保存エントリ、欠落した必須セクション、空の所有キャラ一覧などはロード前に拒否します。ステージIDは仕様が未確定のため、空文字・重複の検査に留めています。StageProgressの保存APIは用意しましたが、解放条件・報酬・クリア処理への新しい接続は追加していません。

**新規ゲームの暫定初期キャラはNachtです。**

NewGameDefaults.StarterCharacterIdsに明示し、後から変更できます。これは既存GameManagerの既定キャラを採用した暫定設定です。初期所持品とステージ進行一覧は空、装備・技はマスター初期値です。ガチャ確率、キャラクターの基本値、合成レシピは変更していません。

戦闘選択画面には所有キャラだけを表示します。図鑑には全キャラを表示し、未所持に[Not owned]を付けます。未所持の詳細閲覧は可能ですが、詳細からの戦闘開始とBattle直接入場でも所有状態を確認します。ガチャは従来どおり単語・素材アイテムの付与だけで、キャラ解放は既存の合成成功処理です。

**戦闘は、判定・状態管理、文章生成、音声再生、画面演出に分かれました。**

| 担当 | 役割 |
|---|---|
| BattleAction／BattleActionResult | 選択した行動、使用可否、命中結果、ダメージ |
| BattleActionResolver | 装備技と行動時点の確認、既存DamageCalculatorによる計算 |
| BattleContext／BattleCombatant | HP、ターン段階、勝敗、結果の一度だけの適用 |
| AdverbContestResolver | 同じ副詞の競合、速度比較、同速時のみ抽選 |
| SentenceContext／SentenceGenerator／BattleSentence | 既存語順・活用、表示用の文章、音声用の単語列とキー |
| AttackAudioPlayback | 文章音声の再生、不足時の単語音声への切り替え |
| BattleManager | UI操作、既存の敵技ランダム選択、演出と再生の進行、結果Sceneへの遷移 |

行動結果は演出前に計算し、ヒット表示の時点で一度だけHPへ適用します。計算と適用を分けたため、演出が早期にHPを変更することや同じ結果の二重適用を防げます。将来の発動タイミング拡張はこの境界に追加できます。今回は遅延攻撃・助動詞の特殊効果・新しい時制は実装していません。

accuracy、cost、effectType、effectValueはSkillDataに維持しています。今回は従来互換として、使用可能な技は命中し、コスト消費を行いません。DamageCalculator自体、相性倍率、敵のランダム技選択、副詞候補・競合ルールは維持しています。冠詞の新しい戦闘効果も追加していません。
