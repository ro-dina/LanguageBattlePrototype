## 保存に関する修正

変更は新規の`Assets/Editor/WebPersistentDataBuild.cs`です。Webビルド完了時、Unity標準テンプレートの`index.html`でコメント化されている次の設定を有効にします。

```javascript
config.autoSyncPersistentDataPath = true;
```

Web以外のビルドには適用しません。想定外のテンプレートなどで有効化を確認できない場合はビルドエラーとして知らせ、永続化できない成果物を黙って生成しないようにしています。

Unity 6000.4.8f1に同梱されているIdbFs.jsを確認し、自動同期が同一フレームのファイル変更をまとめ、進行中の同期には次回同期を予約する実装であることを確認しました。SaveFileStoreの検証・バックアップ・世代切り替えを再実装せず、進行と独立設定の両方をUnityの保存領域全体の同期へ載せています。[Unity公式の修正説明](https://issuetracker.unity.com/issues/18407)

修正前は画面にSavedと出てもIndexedDB内が空で、英語・マスター50%・ボイス60%が再読み込み後に日本語・100%へ戻りました。修正後は実際のIndexedDB内のJSONを読み取り、再読み込み前後で照合しました。

## 容量・メモリ・残る確認

配布フォルダー全体は58,201,686 bytes（約58.2 MB / 55.5 MiB）です。主な配信用ファイルはdata.br約49.2 MB、wasm.br約8.87 MBです。Unityの非圧縮アセット内訳ではテクスチャ65.4 MiB（77%）、その他17.7 MiB（20.8%）が中心で、単独で大きいものは日本語フォント約15.7 MiBとキャラクター画像です。今回は画像・音声・フォントの圧縮設定や画質を変更していません。

検証中に取得した13時点のメトリクスでは、WASM確保領域の最大サンプル約165.6 MiB、WASM使用量約124.2 MiB、JSヒープ使用量約177.0 MiBでした。ブラウザ全体のメモリや連続計測によるピーク値ではありません。ローカル高速配信での起動時間は、インターネット配信のロード時間を示すものではありません。

既存素材の不足も確認しました。Technikの画像、`die_nacht_ist_aktiv`の文章音声、`die`・`nacht`・`aktiv`の単語音声が未収録です。文章音声は既存の単語フォールバックへ進み、存在する`ist`などは再生されます。Feuerの試聴は正常です。これらはWeb固有の読み込み失敗ではなく、該当アセット自体がありません。また、URPのFSRアップスケーリング用シェーダーが非対応というブラウザ警告があり、今回の画面・保存・戦闘検証は継続できました。

Safari・Firefox・iPhone/Android実機、狭い画面のUI、プライベートブラウズ、保存容量不足、タブの強制終了、公開先の配信設定は未検証です。通常幅でのデスクトップWeb動作を今回の完了範囲とします。標準テンプレートのデスクトップキャンバスは960px固定幅なので、狭い表示枠では見切れる場合があります。

自動同期は非同期です。現在のSave成功表示は既存のファイル処理成功を表し、IndexedDBの完了通知まで待つ新しい仕組みは追加していません。通常の再読み込みは検証済みですが、書き込み直後の強制終了や保存領域が拒否された場合の永続化を保証するものではありません。公開前に厳密な保存完了表示・保存失敗の通知が必要なら、次の段階で扱います。

保存先はブラウザ・オリジンと配信パスに依存します。同じデータを使い続ける場合はホスト名・ポート・配置フォルダーを固定してください。Mac版の既存セーブを自動でWebへ移す処理は追加していません。ブラウザのサイトデータ削除で保存が消えることは、今回のバックアップ方式でも防げません。[Unity persistentDataPath](https://docs.unity3d.com/6000.4/Documentation/ScriptReference/Application-persistentDataPath.html)

## 次回の起動方法

成果物はHTMLファイルを直接開かず、ローカル配信から起動してください。新規の`Tools/serve_web.py`はlocalhostだけで待ち受け、Brotli/gzipのContent-EncodingとWebAssemblyのContent-Typeを返します。

既存プロジェクトでFile → Build ProfilesからWebを選び、Buildします。自動同期は上記のビルド後処理で毎回設定されます。出力先をBuilds/Webにした場合は、プロジェクトフォルダーで次を実行できます。

```sh
python3 Tools/serve_web.py Builds/Web --port 8712
```

ブラウザで`http://127.0.0.1:8712/`を開きます。今回用意した成果物を使う場合は、Builds/Webの代わりに`/Users/isao/Documents/ChatGPT/ゲーム/phase110-validation/web`を指定してください。
